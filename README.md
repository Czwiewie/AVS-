# AVS 视觉工坊 1.2.11

面向 SillyTavern 1.19.0 的聊天插画扩展，支持 NovelAI Diffusion 4.5 Full、5 Full、OpenAI 兼容生图、原生 xAI Grok Imagine 与 Google Gemini Nano Banana。

## 安装

将 GitHub ZIP 解压到扩展仓库根目录并提交。根目录需要 `manifest.json`、`studio-entry.js` 和完整的 `src/`。在酒馆的「扩展 → 安装扩展」填写发布后的仓库地址，或更新已安装的仓库并刷新。

如使用三 JSON 游玩包，在酒馆助手的全局脚本库导入并启用 `01` 与 `02`，在世界书导入 `03`。已安装角色视觉档案 V4.2.1 时，停用旧 02，再导入并启用本包的 02。使用原 AVS 悬浮球「文生图」，或打开输入区魔棒菜单的「AVS 插画工坊」。

## 第一次生成

1. 在「连接」配置生图 API。NovelAI 官方地址为 `https://image.novelai.net`，使用账户的 Persistent API Token。「其它生图 API」提供原生 Grok、原生 Nano Banana、NovelAI 兼容和 OpenAI 兼容选四项。按协议填写服务地址与凭证。自动楼层成图需要配置 OpenAI Chat Completions 兼容的提示词 API，参考图分析还要求该模型支持图片输入。
2. 在「画风」可选上传参考图或填写色彩、辅光。分析结果以文字保存。出图时只将可识别的相容色彩和辅光作为局部点缀，线条、画法和构图分析可在界面查看。
3. 在「绘图」点击「一键画当前回复」。工坊自动选择一个有画面感的瞬间。点击「指定正文片段」可轻点起点和终点，再点击「画这一段」。折叠的绘图选项可切换楼层、画幅、张数和自定义参数。NovelAI 模型可在此页切换 4.5 Full 与 5 Full，Grok、Nano Banana 和 GPT Image 的模型与画幅在「连接」设置。「提示词」可编辑自动草稿，也可直接使用手写提示词出图。

## 选段与重画

- 单个段落可点同一项两次，连续段落可点首尾两项。选好后点击「画这一段」。也可用「恢复自动选画面」回到整楼。提示词已完成但首次出图失败时，可在原处点击「用现有草稿重试」。
- 预览和历史中的「重画这张」沿用该图已保存的画面方案和生图参数，直接尝试生成一张，在 NovelAI 上重新随机种子。工坊使用当前保存的相应 API 连接。新版本与旧图并存，可在预览中切换。
- 1.2.10 及之前如果该图使用了人物参考图并且缺少完整请求记录，需要根据该楼层重新提取参考。1.2.11 生成的图片会记录重画所需的参考关联，参考图被移除或更换时会提示。
- 原文、楼层或 Swipe 变更后，旧片段不用于新回复。该版本的选段入口位于视觉工坊「绘图」页。

## 同人角色与楼层档案

在「角色参考」选择已录入的角色，再选择「已确认同人角色」或「非同人角色」并保存。记录按聊天与角色档案 ID 复用。今汐有一条内置候选，含《鸣潮》官方资料链接、人物图和可辨认的外貌特征。其他角色可通过页面上的萌娘百科检索入口查找，再填写原作角色、作品和外貌。所有候选都由用户确认保存。

整楼配图会读取当前 Swipe 对应的档案快照。指定片段时使用该回复之前最近可用的档案，以及片段之前同一楼层的正文，作为背景资料。片段后面的文字和楼末档案不进入该镜头的提示词请求。如果该楼层没有有效快照，已确认的原作身份仍可用，当楼穿搭和动作由正文提供。档案中保留穿戴状态和位置，只有穿戴中的物品会提供完整设计。提示词模型为需要在画面里出现的角色返回档案 ID 和原文证据，工坊验收后在对应人物分栏写入原作身份。剧情明确改动外貌时，草稿采用当楼外貌，并关闭该人物的参考图勾选。当前套装、道具、动作和场景以该楼为准。

可以从已保存的今汐官方资料一键保存人物图，也可以上传自己的 PNG、JPEG 或 WebP。图片保存在当前浏览器。保存好图片后，在「提示词」能看到绑定的人物以及是否发送参考图。Grok Imagine、Nano Banana 与 GPT Image 支持随请求发送生图参考图（每张最多三位人物）。GPT Image 服务须支持 `/images/edits` 的表单请求。NAI 4.5 Full、NAI 5 Full 和通用兼容生图使用人物身份词和外貌描述。历史记录显示随该次出图发送过的参考图人物名。载入旧图提示词时使用当时的文本，重新提取楼层草稿可附带此时保存的人物图。

本版的内置原作资料覆盖今汐。官方图片直读受当前浏览器的跨域权限影响，也可打开原图后上传。各生图线路已通过模拟接口验证，实机成图还需使用对应的真实 API。

## 原生 Grok 和 Nano Banana

在「连接 → 其它生图 API」选择对应协议并填写该服务的 API Key。

| 路线 | 默认 API 地址 | 支持的生图模型 |
| --- | --- | --- |
| xAI 原生 · Grok Imagine | `https://api.x.ai/v1` | Grok Imagine Image 2.0、Grok Imagine Image |
| Google 原生 · Gemini Nano Banana | `https://generativelanguage.googleapis.com/v1beta` | Nano Banana 2.1、2、2 Lite、Pro、初代 Nano Banana |

xAI 用 Images API 的画幅比例和分辨率；2.0 可单独调画质。Google 用 Interactions API，明确请求图像并读取最终输出，按型号提供画幅和分辨率。这两条线路独立保存配置，服务商仍需允许当前浏览器跨域访问。OpenAI 兼容中转仍用「OpenAI 兼容图片生成」。[xAI 官方生图文档](https://docs.x.ai/developers/model-capabilities/images/generation) · [Gemini 官方生图文档](https://aistudio.google.com/docs/image-generation)

## 第三方生图接口与回图

在「连接 → 其它生图 API → OpenAI 兼容图片生成」填写服务商提供的基础地址、密钥和生图模型名。第三方需要开放 `POST /v1/images/generations`，并允许酒馆页面跨域调用。模型列表可获取只说明列表接口可用。

「回图格式」默认沿用服务商设置。识别到 GPT Image 模型 ID 时，工坊自动使用服务商默认格式，兼容出图的请求中省略 `response_format`。切回其他模型后恢复之前的回图选项。服务商完全自定义的模型别名如无法识别，可手动选「服务商默认」。

若错误指出生图接口已返回链接但浏览器无法下载图片，可在其他模型的服务商支持 `response_format: "b64_json"` 时选择「Base64」并保存，再用保留的草稿出图。链接方式要求图片地址允许当前酒馆网页直接读取。工坊按接口响应、响应体或图片链接三个阶段显示失败原因，每次操作只提交用户选择的张数。

## 二维立绘画风

所有路线的实际出图提示词固定将近年《碧蓝航线》式二维立绘放在最高优先级。美术要求覆盖清楚的整体轮廓、有粗细变化的细线、彩色内轮廓、分层赛璐璐阴影、局部手绘过渡、细致的眼部和发束、分材质高光，以及主次分明的细节密度。保留实际楼层的角色、动作、服饰、空间和画幅。

NAI 使用标签与人物分栏，GPT Image、Grok 和 Nano Banana 采用自然语言。用户参考图最多提供一项局部色彩和一项辅光，二者从限定的相容提示词中选取。参考图分析原文、附加画师词和参考负面词仍保存在预设中。自动生成、手写、提示词复制和历史重用均应用当前画风规则。历史详情保留原图实际发送的提示词。

第三方使用完整的 NovelAI 模型 ID 时，绘图页自动选中对应按钮，切换按钮也会同步修改连接的模型名。服务商使用别名时，NovelAI 兼容协议下的两按钮用于指定对应参数格式，模型名按服务商提供的别名发送。其它通用 OpenAI 图片模型在连接页选择。

## 学院风主题

角色档案、悬浮球菜单、独立 API、扫楼、世界书与预设选择、衣橱和视觉工坊共用蓝白主题。按钮分为主操作、次要操作与危险操作，提供选中、按压、键盘焦点和停用状态。删除、停用、补全等已有确认步骤使用带取消和确定按钮的主题弹窗。Core 的普通通知也使用同一套配色。AVS 档案菜单、工坊、独立 API 和其它 AVS 弹窗从可见屏幕上方展开，水平居中。键盘弹出时跟随可见区域调整，长表单可在窗口内滚动。作品沿用 AVS 自己的界面结构。

## 进阶使用

- 提示词请求从楼层正文提取一个画面。会剔除常见规划、分析、状态栏和选项块；在模型输出带解释、代码围栏或兼容 SSE 时识别符合字段契约的完整画面对象。若图像 API 失败，可在「提示词」页使用保留的草稿重试。
- NovelAI 回图支持 ZIP、独立图像及带最终帧的 MessagePack；图像服务返回 HTML、输出截断、缺最终帧或 Anlas 不足时会直接报告该阶段原因。
- 1.2.5 的源码对照与验证范围见 [三仓链路核查](docs/workflow-audit.md)。

- **绘图**支持常用画幅、自定义尺寸、采样器、步数、引导强度、CFG Rescale、质量标签、随机或固定种子及 1～4 张出图。多张串行发送，固定种子按张递增。等待服务商时进度条显示已返回张数。
- **绘图预设**可选剧情竖幅、宽幅场景、快速构图，也能将当前模型和画布、采样、种子等参数另存为自定义预设。预设不保存密钥或画风。
- **提示词**支持全局正面词、负面词、独立人物分栏、复制最终提示词与单独启停画风叠加。角色档案和之前两条 AI 回复可用于辅助理解当前画面。手写模式可仅配置生图 API。
- **历史**按同一聊天的楼层和 Swipe 查看最近 30 张，另有手写绘图区。可打开原图、下载、查看种子及参数、载入原提示词和生成参数、删除本机记录。图像保存在当前浏览器。两张以上时可展开「并排比较生成结果」，选择左右两幅图。「查看出图参数与提示词」可以追溯实际参数及正负面词。载入历史时使用已包含画风的最终提示词。
- **连接**支持从可上下滑动的单列弹窗选取模型，或手填模型名。勾选使用预设后，从 SillyTavern 的对话补全预设中选择。工坊采用该预设启用的静态系统提示以及兼容的采样和推理设置，仍以本次生图任务和结构化输出为准。取消勾选后，工坊保留基本任务指令，模型推理由服务商默认控制。AJAX 调用由酒馆页面发起，服务地址需允许当前站点访问。密钥默认保存在当前浏览器会话，勾选记住后在本机浏览器持久保存。
- **取消任务**会停止浏览器继续等待和提交后续图片，已完成的图片保留，已提交到服务商的任务由服务商处理。

功能参考：[智库](https://github.com/ruoege49-ship-it/zhiku-tavern-helper)、[ST-BaiBai-Image](https://github.com/wuhehen176/ST-BaiBai-Image)、[witch-paintbox](https://github.com/Elainadesne/witch-paintbox)。

第三方模型列表使用对应服务的 `GET /models`，只列出接口返回的模型 ID。OpenAI 兼容回图支持直接图片、Base64 和可直接访问的图片链接。旧版配置的自定义 NovelAI 地址迁移至「其它生图 API」。

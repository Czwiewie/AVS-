# AVS 视觉工坊 1.0.2

用于 SillyTavern 1.19.0 的聊天插画扩展。上传一张参考图提取画风，选择最新或指定楼层的 AI 回复，即可请求 NAI 4.5 Full 或 NAI 5 Full 生成插画。

## 安装

将此包解压到 GitHub 扩展仓库根目录并提交。根目录应直接显示 `manifest.json` 与 `studio-entry.js`，并包含完整的 `src/` 目录。发布后在酒馆的「扩展 → 安装扩展」粘贴该仓库地址。若酒馆已安装同一个仓库，可更新该扩展并刷新页面。

视觉工坊可从聊天输入区的扩展菜单进入。有 AVS 悬浮球时也可点击「文生图」。正式三 JSON 导入包的第二份已内置相同工坊，可独立使用。将 GitHub 版用作扩展入口时，保留一种活动的视觉工坊版本。

## 使用

1. 在工坊的 API 设置中填入支持图片输入的 OpenAI Chat Completions 兼容服务地址、模型名与密钥。填写 NovelAI Token 和模型。官方生图地址为 `https://image.novelai.net`。自定义生图服务应兼容原生 `POST /ai/generate-image`，并允许酒馆页面跨域访问。
2. 上传参考图。视觉 API 提取线条、色彩、光影、渲染与构图手法。工坊将这些美术特征以文字交给 NAI。生成时沿用已保存的画风。
3. 等 AI 回复完成，选择最新回复或指定楼层，点击「生成插画」。同一楼层按聊天和分支保存预览，提供原图下载。角色档案存在时可提供当时的外貌与穿着资料。未录入角色也可以作画。

`src/studio.js` 管理交互和预览，`src/scene.js` 读取目标楼层和可用角色资料，`src/api.js` 处理画风提取、提示词规划、NovelAI 请求和图片解析。

# AVS 视觉工坊 1.2.4

面向 SillyTavern 1.19.0 的聊天插画扩展，支持 NovelAI Diffusion 4.5 Full 和 5 Full。

## 安装

将 GitHub ZIP 解压到扩展仓库根目录并提交。根目录需要 `manifest.json`、`studio-entry.js` 和完整的 `src/`。在酒馆的「扩展 → 安装扩展」填写发布后的仓库地址，或更新已安装的仓库并刷新。

如使用三 JSON 游玩包，在酒馆助手的全局脚本库导入并启用 `01` 与 `02`，在世界书导入 `03`。从 1.2.3 升级时，停用旧 02，再导入并启用本包的 02。使用原 AVS 悬浮球「文生图」，或打开输入区魔棒菜单的「AVS 插画工坊」。

## 第一次生成

1. 打开「连接」，官方地址为 `https://image.novelai.net`，填写 NovelAI 账户的 Persistent API Token 即可鉴权。其它生图 API 可选择兼容 NovelAI 的 `/ai/generate-image` 或 OpenAI 的 `/images/generations`，填服务商提供的地址、密钥和模型。楼层规划或参考图分析需要支持图片输入的 OpenAI Chat Completions 兼容接口。
2. 打开「画风」，上传参考图，或填写自定义美术特征和画师串。上传后会保存线条、色彩、光影、渲染和构图的文字描述。可切换多个预设，也可选不叠加画风。
3. 「绘图」页顶部并排显示 NAI 4.5 Full 和 NAI 5 Full。点选模型后，再选楼层和画幅，点「生成插画」。想手动控制则到「提示词」，先提取草稿再改词，或使用「手写提示词」直接出图。

第三方使用完整的 NovelAI 模型 ID 时，绘图页自动选中对应按钮，切换按钮也会同步修改连接的模型名。服务商使用别名时，NovelAI 兼容协议下的两按钮用于指定对应参数格式，模型名按服务商提供的别名发送。其它通用 OpenAI 图片模型在连接页选择。

## 学院风主题

角色档案、悬浮球菜单、独立 API、扫楼、世界书与预设选择、衣橱和视觉工坊共用蓝白主题。按钮分为主操作、次要操作与危险操作，提供选中、按压、键盘焦点和停用状态。删除、停用、补全等已有确认步骤使用带取消和确定按钮的主题弹窗。Core 的普通通知也使用同一套配色。AVS 档案菜单、工坊、独立 API 和其它 AVS 弹窗从可见屏幕上方展开，水平居中。键盘弹出时跟随可见区域调整，长表单可在窗口内滚动。作品沿用 AVS 自己的界面结构。

## 进阶使用

- **绘图**支持常用画幅、自定义尺寸、采样器、步数、引导强度、CFG Rescale、质量标签、随机或固定种子及 1～4 张出图。多张串行发送，固定种子按张递增。等待服务商时进度条显示已返回张数。
- **绘图预设**可选剧情竖幅、宽幅场景、快速构图，也能将当前模型和画布、采样、种子等参数另存为自定义预设。预设不保存密钥或画风。
- **提示词**支持全局正面词、负面词、独立人物分栏、复制最终提示词与单独启停画风叠加。角色档案和之前两条 AI 回复可用于辅助理解当前画面。手写模式可仅配置生图 API。
- **历史**按同一聊天的楼层和 Swipe 查看最近 30 张，另有手写绘图区。可打开原图、下载、查看种子及参数、载入原提示词和生成参数、删除本机记录。图像保存在当前浏览器。两张以上时可展开「并排比较生成结果」，选择左右两幅图。「查看出图参数与提示词」可以追溯实际参数及正负面词。载入历史时使用已包含画风的最终提示词。
- **连接**支持从可上下滑动的单列弹窗选取模型，或手填模型名。勾选使用预设后，从 SillyTavern 的对话补全预设中选择。工坊采用该预设启用的静态系统提示以及兼容的采样和推理设置，仍以本次生图任务和结构化输出为准。取消勾选后，工坊保留基本任务指令，模型推理由服务商默认控制。AJAX 调用由酒馆页面发起，服务地址需允许当前站点访问。密钥默认保存在当前浏览器会话，勾选记住后在本机浏览器持久保存。
- **取消任务**会停止浏览器继续等待和提交后续图片，已完成的图片保留，已提交到服务商的任务由服务商处理。

功能参考：[智库](https://github.com/ruoege49-ship-it/zhiku-tavern-helper)、[ST-BaiBai-Image](https://github.com/wuhehen176/ST-BaiBai-Image)、[witch-paintbox](https://github.com/Elainadesne/witch-paintbox)。

第三方模型列表使用对应服务的 `GET /models`，只列出接口返回的模型 ID。OpenAI 兼容回图支持直接图片、Base64 和可直接访问的图片链接。旧版配置的自定义 NovelAI 地址迁移至「其它生图 API」。
